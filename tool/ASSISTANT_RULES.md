# 대화 규칙 v1

`assets/assistant_rules.json`은 앱 업데이트와 함께 배포되는 기능 목록입니다.
등록된 기능의 `utterances`를 추가하면 같은 기능을 새 표현으로 실행할 수 있고,
`questions`와 `description`을 수정하면 최신 사용 안내를 재학습 없이 제공합니다.
정확 일치 외에 `search_groups`의 동의어 그룹으로 관련 기능을 검색합니다.
모든 그룹이 일치해야 후보가 됩니다. 후보가 하나이며 명시적 실행 요청일 때만
실행합니다. 사용법 질문은 기능 설명을 반환하고 복수 후보·부정·복합 요청은
보류합니다. 임베딩이나 SLM 기반 의미 검색은 아직 구현하지 않았습니다.
새 기능 실행 코드는 AssistantScreen에 별도로 구현해야 합니다.

AssistantScreen은 실행 직전 현재 분석 상태와 결과 유무를 검사합니다.
코드에 있는 필수 검사는 JSON으로 해제할 수 없습니다. 잘못된 규칙 파일은
실행 실패로 처리합니다. 기존 AssistantIntent는 호환용으로 유지합니다.

SLM 연결용 validateProposal은 앱이 독립적으로 해석한 명령과 모델 제안이
일치할 때만 명령을 통과시킵니다. 모델의 문장이나 근거가 포함된 분석 답변은
이 명령 검사에서 통과시키지 않습니다. 분석 답변용 근거 검사는 별도 과제입니다.
contextJson은 향후 추론 프롬프트에 넣을 최신 기능 정보를 제공합니다.
현재 새 SLM 추론 호출이나 자동 실행은 연결하지 않았습니다.

## 검증 (2026-09-23)

- 기존 의도 파서 17건 통과.
- 새 규칙 테스트 12건: 규칙 추가, 안내 변경, 진행 중 변경 차단,
  결과 없는 영상 요청, 잘못된 모델 명령, 등록되지 않은 기능 등 통과.
- 학습 모델의 264건 출력을 새 명령 검사에 재생: 잘못된 실행 제안 32건 차단.
  단 실행 허용도 0건으로, 테스트의 새로운 표현에 대한 커버리지가 매우 낮음.
  이를 정확도 개선이나 실사용 성공으로 해석하면 안 됩니다.
- 생성된 문장에는 의미 오류도 있음. 숫자 일치율이 답변 품질을 보장하지 않음.

v2에서는 기능 검색과 질문/실행 의도 분리를 추가했습니다.
새로 작성한 검색·질문·복합 요청·상태 검사 26건과 기존 29건이 통과했습니다.
이는 제한된 회귀 테스트이며 일반적인 한국어 이해 정확도를 뜻하지 않습니다.
다음 단계는 기기에서 검색 범위와 UX 검증 및 후보 모델 연동입니다.
현재 후보 모델은 배포하지 않습니다.
후속 검증: SM-F741N에 APK(148486619 bytes)를 재설치했습니다.
APK 내부 규칙 JSON이 원본과 같은지 확인했고, 폰에서 대화창의 설정 버튼으로
규칙 로딩 및 설정 화면 진입을 확인했습니다. 한글 자연어 실제 입력·음성 검증은
아직 수행하지 않았습니다. VM을 통한 화면 메서드 호출은 compilation service
부재로 실패했으므로 검증 성공으로 집계하지 않습니다.
