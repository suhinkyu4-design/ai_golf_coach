# 1단계 코칭 설계 — 드라이버 / 7번 아이언

승인 범위: Driver(driver), 7i만 지원. 과거 다른 클럽 기록은 보존하며 다른 클럽의 기준으로 바꾸지 않는다.

## 먼저 구현할 항목
- 정면: 머리(양 눈 중심)·골반(양 고관절 중심)의 좌우/상하 이동.
- 후방: 골반 이동과 영상상 상체 기울기 변화. 골반 관절 중심은 엉덩이 윤곽선과 다르다.
- 비교 단위: 어드레스 때 어깨 중심과 골반 중심 사이의 영상상 길이. 고정된 분모를 사용한다. 어깨너비는 후방에서 짧게 투영될 수 있어 사용하지 않는다.
- 화면 좌표의 오른쪽/아래를 양수로 저장한다. 타깃 방향 및 공 방향을 확인하기 전에는 타깃 쪽/공 쪽으로 번역하지 않는다. 왼손 및 좌우 반전 영상 검증이 필요하다.
- 고정 카메라가 전제다. 크기가 같아도 카메라 이동/줌이 없는 것을 보장하지 못하므로 품질 검증 전에는 동작 오류를 확정하지 않는다.

## 현재 구현과 남은 작업
구현: 두 클럽 선택, 확인된 키프레임 사이의 머리/골반/어깨 이동량, 품질 누락 처리, 측정 보고서 및 기존 데이터셋 내보내기에 포함.
각도 분석은 어드레스·탑·임팩트·피니시 네 프레임을 사용한다. 이동 분석은 어드레스~임팩트 사이의 추가 샘플을 사용한다. 움직임 시작/각속도 정점은 아직 측정하지 않는다.
남은 작업: 실제 영상 연속 샘플 검증 → 카메라/방향 품질 검사 → 참고 영상의 동일 분석 → 클럽/방향별 참고 분포 검증 → 관찰-연습 자료 연결 → SLM 입출력 확장과 평가 → 최종 코멘트 화면.
기존 SLM은 한 관절 설명용이다. 새 관찰값을 그 모델에 보내지 않는다. 새 코칭이 완료됐다고 표시하지 않는다.

## 참고 기준 후보
- https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2026.1867187/full : 여성 프로 12명의 3D 클럽 비교. 드라이버/7번 아이언 포함. 앱의 2D 판정 임계값으로 사용 금지.
- https://pmc.ncbi.nlm.nih.gov/articles/PMC7044058/ : 고령 남성 드라이버/6번 아이언. 이번 7번 아이언 기준으로 대체 사용하지 않는다.
- https://github.com/damilab/CaddieSet : 다양한 실력 8명, 공개 설명상 1757샷. 정석 정답 라벨이 아님. 버전/클럽별 표본 수/계산 정의 확인 필요.
- https://github.com/wmcnally/golfdb : 영상과 이벤트 기준 후보. 이용 조건 및 영상 접근성 확인 후 재측정 후보 선정.
- https://www.mytpi.com/improve-my-game/swing-characteristics/sway : 하체 측면 이동의 정의. 머리 움직임만으로 스웨이 판정 금지.
- https://www.titleist.eu/instruction/stop-early-extension : 골반의 공 방향 이동 및 일어섬 관찰 주제. 사용자 원인 확정 근거는 아님.

## 참고 프로필 계약
club, view, phase_interval, metric_definition_version, camera_constraints, population, participant_count, swing_count, source, license_status, distribution, measurement_error, validation_status를 보관한다.
검증 전에는 정상 범위 및 오류 임계값을 null로 유지한다. 사람 단위로 학습/평가를 나누며 같은 사람의 여러 샷을 독립 인원으로 세지 않는다.

## 코칭 출력 계약
observation_ids, reference_ids, drill_id, summary, reason, next_check, confidence를 사용한다.
새 수치/원인/비거리 손실을 생성하지 않는다. 오류 이름은 패턴 검출 검증 후에만 사용한다. 자료 불충분은 측정 관찰로 명시한다.
X-Factor 및 실제 3D 운동 순서는 2차 범위이며 2D 선 기울기/이동 속도로 대체하지 않는다.

## 연속 샘플 분석 추가
어드레스~임팩트 구간을 목표 33ms 간격, 최대 91개로 균등 추출한다. 긴 구간은 간격이 늘어난다. 실제 프레임 PTS가 없어 각속도나 운동 순서 계산에 사용하지 않는다.
양쪽 눈 좌표 저장을 추가했다. 눈 중심은 가림/회전에 민감하므로 머리 중심의 대용 지표이며, 후방에서 측정 불가가 정상이다.
백스윙/다운스윙별 각 그룹의 유효 샘플 3개 이상, 유효 비율 70% 이상에서만 샘플 내 최대 이동을 요약한다. 이는 품질 휴리스틱이며 정상 자세의 기준이 아니다. 좌우 및 상하 최대치는 서로 다른 시각일 수 있다.
보고서 trajectory와 분석 상세의 접힌 이동량 카드에 연결했다. 참고 패턴 검증 및 SLM 신규 코칭 연결은 아직 미구현이다. 카메라 움직임·포즈 점프·샘플 사이의 실제 최대치는 검증하지 못하므로 오류 판정으로 사용하지 않는다.
