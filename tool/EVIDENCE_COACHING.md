# 현재 방식: 측정값과 참고 자료로 설명하기

지도자 의견·승인을 앱 사용이나 SLM 실험의 필수 조건에서 제외했습니다.
현재 앱은 추가 학습 없이 사용할 수 있는 입력 자료를 구성하며, 실제 SLM 실행은 아직 연결하지 않았습니다.

## 앱에서 달라진 점

- 측정값이 있으면 지도자 검토 대기 대신 시점 간 변화 설명을 표시합니다.
- 후방/타깃 라인 영상: 어드레스→임팩트의 영상상 몸통 기울기를 비교합니다.
- 확인 가능한 경우: 탑→임팩트의 영상상 리드 팔꿈치 각도를 비교합니다.
- 촬영 방향 불명, 시각 미확인, 관절 신뢰도 부족, 측정값 누락이면 비교를 만들지 않습니다.
- 관련 자료를 접이식 카드로 표시하며 연결 이유, 요약, 출처와 링크 복사를 제공합니다.
- 내보내기 이름은 `측정값과 참고 자료 내보내기`입니다.

변화량을 문제의 크기로 해석하지 않습니다. 측정 신뢰도는 각도 정확도 확률이 아닙니다. 같은 영상에서 얻은 2D 값이며 3D 회전, 체중 이동, 실제 척추 각도나 클럽 페이스를 뜻하지 않습니다.

## 참고 자료

초기 로컬 자료는 두 주제로 제한했습니다. 자료 선택은 주제 연결이며 개인의 결함을 검출했다는 뜻이 아닙니다.

- [PGA: How to Maintain Your Spine Angle](https://www.pga.com/story/golf-tips-how-to-maintain-your-spine-angle-for-more-speed): 몸통 자세 관련 참고 링크. 앱의 몸통 기울기 수치만으로 조기 신전이나 원인을 진단하지 않습니다.
- [PGA: Feet Together Drill to Improve Balance and Tempo](https://www.pga.com/story/feet-together-drill-to-improve-balance-and-tempo): 천천히 하는 빈스윙에 관한 일반 연습 자료. 사용자에게 균형 문제가 있다고 판정하지 않습니다.

앱에 들어간 설명은 짧게 새로 작성한 요약과 사용 안내입니다. 기사·영상 원문 전체를 저장하거나 학습하지 않습니다. 해당 기관의 보증이나 전체 콘텐츠 사용 허가를 받았다는 뜻은 아닙니다.

## 내보내기 형식

`schema_version: golf_coaching_evidence_2.0`

- input: 촬영 조건, 자세 시각, 측정값과 측정 품질.
- coaching_context.facts: 앱이 계산한 사실, 원본 metric ID, 비교 전후 값과 변화량.
- coaching_context.resources: 연결된 자료 ID, 요약, 연결 이유, 출처 URL.
- coaching_context.slm_executed: false. 현재는 로컬 규칙/문구로 구성합니다.
- training_target: null. 생성한 설명을 정답으로 취급하지 않습니다.
- review/reviewer_id/approved 필드는 없습니다.
- training_consent의 기본 false는 향후 학습 사용 동의에 관한 메타데이터이며 현재 앱 설명을 차단하지 않습니다.

원본 영상과 기기 파일 경로는 내보내지 않습니다. 예제 JSON은 이전 폰에서 측정한 수치에 새 자료 연결 로직을 PC에서 적용한 것으로, 새 버전의 폰 실행을 검증한 기록은 아닙니다.

## Colab에서 시험

1. `golf_evidence_inference.ipynb`를 Colab에 업로드합니다.
2. 첫 셀에서 v2 내보내기 JSON 한 개를 선택합니다. 준비된 예제로 형식을 확인할 수도 있습니다.
3. GPU 런타임에서 기본 모델을 불러옵니다. 지도자 정답 업로드, LoRA 학습은 없습니다.
4. 계산된 사실과 자료 요약을 함께 전달해 설명을 생성합니다.
5. 출력 필드와 근거 ID 검사를 거쳐 결과를 다운로드합니다. 검사를 통과해도 문장의 사실성이나 교정 효과가 보증되지는 않습니다.

이 노트북은 아직 실제 GPU에서 실행하지 않았습니다. 휴대폰에서 실행할 SLM 모델이나 런타임은 포함하지 않습니다.
기존 `golf_coaching_qlora.ipynb`, `prepare_coaching_dataset.py`는 정답 데이터가 있을 때 쓰는 이전 실험으로, 현재 앱의 필수 절차가 아닙니다. 이전 파일의 승인 검사를 단순히 해제해 가짜 정답을 학습시키지 않습니다.

## 검증한 범위

- 각도 계산 회귀 테스트 통과.
- 자료 연결, 측정 변화 계산, 촬영 방향 구분, 저신뢰도/누락/시각 미확인 차단 테스트 통과.
- 지도자 필드 제거, 정답 null, 경로 미포함 내보내기 테스트 통과.
- 변경한 Dart 파일 정적 검사에서 오류 없음. 기존 스타일 안내 2건은 남아 있습니다.
- 새 Colab 노트북 코드 셀 문법 검사 통과. 모델 다운로드/실제 추론은 실행하지 않았습니다.

현재 수정본의 APK 빌드·폰 재설치 및 화면 확인은 별도로 남아 있습니다.
