# 대화창 모드 — 2026-09-23

기본 홈은 대화창. 설정에서 기존 메뉴 모드로 전환하며 선택을 로컬 저장한다.
현재 구현은 앱 명령 목록과 측정 결과를 연결한 결정적 안내 도우미이다. 모든 기능을 학습한 SLM 또는 범용 자연어 에이전트가 아니다. 기존 golf_q8_v1은 단일 관절 수치 설명용이므로 명령 실행에 전용하지 않는다.

## 실행 연결
- 음성/텍스트/선택 버튼 → AssistantIntent → 허용된 화면/설정 함수.
- 촬영·갤러리는 기존 영상 처리 파이프라인을 재사용. 완료하면 대화 홈으로 복귀하여 실제 결과를 자동 표시.
- 음성 대화는 마이크 버튼으로 시작하는 1회 입력이며 촬영 음성 설정과 별도. 카메라에서는 기존 시작/종료 인식을 유지.
- 설정/상세 화면에 대화 복귀 및 음성 요청 컨트롤. 시스템 갤러리와 권한 화면은 OS UI를 사용.
- 촬영방향/손/클럽 기본값을 영속화하며 이미 분석한 기록에는 소급 적용하지 않는다.
- 불명확/부정 문장은 설정을 변경하지 않고 선택지를 안내한다.
- 측정 불가를 정상으로 설명하지 않는다. 교정 안내는 기존 앱 판정과 가이드 사용.

## 범위와 다음 SLM 단계
현재 대화는 앱 실행 동안 유지되며 대화 모드를 재생성하거나 프로세스가 종료되면 초기화된다. 기존 스윙 기록도 실행 세션 목록이다.
자유로운 문장, 복합 요청, 긴 맥락 대화에는 별도 SLM 의도 해석 및 평가가 필요하다.
학습 계약은 사용자 발화 + 현재 화면 + 허용 기능 + 분석 사실 → action/arguments 또는 설명 근거 ID. 실행 결과가 성공한 뒤에만 완료를 답변한다. 앱 기능 문서는 버전별 관리하고 모델에 측정값을 암기시키지 않는다.
검증 데이터에 부정/취소/복합/모호한 요청, 이전 기록과 현재 기록 구분, 측정 불가 및 테스트 샷 구분을 포함한다.

## 검증
- AssistantIntent 회귀 테스트 17개.
- Android 빌드 및 연결 폰 설치.

- 최종 변경 사항의 세부 UI 검증은 작업 기록 참조.
